# Clipora video replacement folder

All website videos are loaded from this folder. Replace a file with another file using the **same filename** and redeploy; the website updates automatically. No HTML or JavaScript changes are required.

## Landscape — 16:9 recommended
- `landscape/hero.mp4` — homepage editor source video
- `landscape/editor.mp4` — editing/features sections
- `landscape/webinar.mp4` — webinar/education sections
- `landscape/podcast.mp4` — podcast use-case section
- `landscape/founder.mp4` — founder/about sections
- `landscape/review.mp4` — team review section
- `landscape/register.mp4` — registration page
- `landscape/login.mp4` — login page
- `landscape/forgot-password.mp4` — password recovery page
- `landscape/verify.mp4` — email verification page

Recommended: MP4 H.264, 1280×720 or 1920×1080, 8–20 seconds, under 5 MB, no audio required because previews autoplay muted.

## Portrait — 9:16 recommended
- `portrait/product.mp4` — product output preview
- `portrait/quality.mp4` — output inspection section
- `portrait/tool.mp4` — free tool preview
- `portrait/auth-card.mp4` — small registration output card

Recommended: MP4 H.264, 720×1280 or 1080×1920, 8–15 seconds.

## Square — 1:1 recommended
- `square/social-preview.mp4` — product 1:1 format preview

Recommended: MP4 H.264, 1080×1080, 8–15 seconds.

## Posters
Replace matching JPG files inside `posters/` to control what appears before a video starts or when autoplay is unavailable.
